# v0.2.0 需求補充

原 PRD（`PRD.md`）與 v0.1.3 的補充需求（交接包 `prd/REQUIREMENT_UPDATES.md`）保留不改。以下為 2026-10-14 與使用者確認、於 v0.2.0 實作的需求。

## 對位

- **分析通道（NMC/Ni、次要相、PVDF/F）維持不重採樣、不拉伸。** 對位只靠整數像素平移：裁切框可用按鈕或方向鍵每次移動 1 px（Shift 為 10 px），寬高不變。
- 預覽提供三種人工檢查方式：混合比例、逐像素差異、按住顯示參考圖。任何調整都會取消「已確認」勾選，須重新確認才能匯入。
- **例外：SEM/BSE 只作為顯示底圖，不進入任何指標，因此允許縮放。** 使用者在 SEM 上框出元素圖實際掃描的區域，工具把該區重採樣為參考通道的尺寸。
  - 縮小採面積平均、放大採雙線性內插，以純 JavaScript 計算，不使用 canvas 內建縮放，確保不同瀏覽器結果一致。
  - 可鎖定參考圖長寬比；未鎖定且兩軸縮放比相差超過 2% 時顯示警告。
  - `importInfo` 記錄 `pixelResampling`、`scaleX`、`scaleY`、`crop`、`lockAspect`、`displayOnly`，並寫入 Session 與分析 trace。
  - 非 SEM 通道一律拒絕重採樣。
- 仍不提供自動 registration、旋轉或分析通道的縮放。

## ROI 與尺度校正的清除規則

ROI 與尺度校正屬於「分析格點」。下列情況清除：

- 更換或重新裁切既有的分析通道。
- 分析格點尺寸改變。

下列情況保留：

- 新增通道，且尺寸與分析格點相同。
- 已載入分析通道時，新增、更換或重新貼合 SEM／其他元素（僅供顯示）。尺寸不符時阻擋分析，但不清除。

檔案匯入與貼上裁切採同一規則。

## 黏結劑鄰域距離

- 未自訂時，隨單位切換預設值（3 px／0.5 μm）。
- 已自訂時，設定或清除比例尺會依比例換算，保留同一物理距離，並在狀態列顯示換算後的數值。

## Session

- 維持 `schemaVersion: 1`；新欄位皆為選填，v0.1.x 的 Session 可直接載入。
- 載入前先完整驗證並解碼，失敗時不更動目前工作區。內嵌 PNG 的實際尺寸須與通道尺寸相符；未知欄位會被捨棄。

## 其他

- 「清除本機資料」改名為「重設工作區」：工具不在本機儲存任何資料。
- 樣本材料體系：次要相為 LFP，Fe 圖放「次要相／添加物」通道，添加物選 LFP。

## 尚待驗收

Windows／VDI 實機操作（含本版新增的對位操作）、實驗影像的科學對位、尺度與遮罩有效性，仍需在目標環境確認。

# v0.2.1 需求補充

2026-10-14，依使用者在 v0.2.0 的實機試用回饋。

## 匯入不應要求手動對齊像素尺寸

- 報表式影像自動框出有效區域（元素圖：淺色頁面上的深色矩形；SEM：標示掃描區的亮線框內側）。偵測結果只是起始建議，仍須人工勾選確認才匯入；偵測不到時維持整張圖。
- 已有分析通道時，後續通道的裁切框預設鎖定為分析格點尺寸，只能移動位置。使用者可取消鎖定，以重新決定整組尺寸。
- 「分析格點」取已載入分析通道共用的尺寸；通道彼此不一致時取多數，分析通道優先。SEM 的縮放目標是分析格點，與對位參考通道的選擇無關。
- 以檔案匯入的影像若偵測到可裁切區域或尺寸不符格點，與貼上相同，先進裁切確認；不需要裁切且已符合格點者直接匯入。

## 阻擋計算的問題必須看得見

- 尺寸不一致時，在影像上方顯示提示列，指出不符的通道與目標尺寸，並提供開啟修正的按鈕。其他錯誤訊息同樣顯示於此。
- 無法分析時，分析按鈕下方說明原因。

## 檢視

- 「元素疊圖」：元素圖以原色疊在 SEM 上，可勾選元素，預設顯示次要相。僅為顯示，不影響任何計算。
- 原「疊圖」改名「遮罩疊圖」，並標示遮罩所屬通道。
- 各步驟提供一行說明與「下一步」；分析區域標示為可不設定，並提醒尺度校正在同一步驟。


# v0.3.0 需求補充

來源：使用者實機試用 v0.2.2 後的回饋（2026-10-14），以及用其樣本圖檢查自動遮罩的結果。

## 尺度校正在裁切時完成

原本尺度校正在「分析區域」頁，但那時比例尺已被裁掉，無法量測。改為在裁切視窗的原圖上自動找出比例尺，使用者只輸入圖上標示的長度。「資料」頁保留一個 μm／像素欄位，供 CSV 等不經裁切的輸入使用。原本在主畫面點選比例尺兩端的功能移除。

尺度的清除規則隨之調整（取代 v0.2.0「ROI 與尺度校正的清除規則」中關於尺度的部分；分析範圍的規則不變）：尺度是原圖每像素的 μm，而分析通道不重採樣，所以**重新裁切同一張原圖不會改變尺度，尺度保留**。把分析通道換成另一張影像時，除非輸入該影像的比例尺長度，否則尺度清除；裁切視窗會在套用前提醒。

## 流程由四步改為三步

資料 → 確認遮罩 → 分析。「分析區域」不再是獨立步驟：裁切準確時就是分析整張影像，只有影像中包含不該計入的部分時才需要，因此收合在分析頁的「限定分析範圍（選用）」。Al₂O₃ 截面仍必須先排除集流體，此時該工具自動展開。

## 遮罩預設先平均再取閾值

以使用者的 Ni／Fe／F 圖（254×94 px）檢查：逐像素取閾值時，Ni 遮罩只覆蓋 31% 且呈雪花狀；半徑 2 px 平均後覆蓋 59%，形狀與 SEM 上的顆粒相符。使用者確認預設半徑 2 px。這會改變所有指標的數值，因此舊版 Session 維持不平均，半徑記錄於 trace。

「確認遮罩」頁同時以三種顏色顯示三個通道的遮罩與各自的覆蓋率；閾值等控制項收合在「遮罩不對時再調整」。

## 分析結果依範圍呈現

進入分析頁即自動計算。網格疊在影像上，每格標示次要相的局部面積比例；點一格，右側改顯示該格的數值。每個指標附一行白話說明。匯出的疊圖 PNG 放大為整數倍並包含網格與比例尺。

## 尚待驗收

- 比例尺偵測只以這一種報表版面（線段加兩端刻度）與合成圖驗證。
- 平均半徑 2 px 是依這一組影像選定；倍率或計數密度差異大的影像可能需要調整。
